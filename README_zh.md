# Unofficial SoftEther VPN

由 M0Sheng 独立开发的 Android 客户端，兼容 SoftEther VPN，用于连接个人或组织管理的服务器。使用前请准备服务器地址和账号。[English](README.md)

预发布版本 **1.8.67**（247）支持 **Android 16 及以上版本**。可在「设置 → 外观与快捷操作 → 应用语言」切换简体中文、英语和日语。

[v1.8.68 预发布页](https://github.com/M0Sheng/Unofficial-SoftEther-VPN/releases/tag/v1.8.68)提供五个签名 APK 和 SHA-256 校验文件。按设备架构选择 `armeabi-v7a`、`arm64-v8a`、`x86` 或 `x86_64`。不确定架构时，下载覆盖全部四种架构的 `-universal.apk`。应用 ID 为 `io.github.m0sheng.unofficialsoftethervpn`。

## 从旧版迁移

从旧应用 ID 迁移配置时，先在旧版断开 VPN，再从各配置的菜单选择「导出 .vpn」。打开新版，在「配置」中选择「导入」，按认证方式重新输入密码或导入客户端证书与私钥。使用 TUN 时重新授予系统 VPN 权限，使用 TAP 时重新授予 Root 权限，并按需重新设置分应用路由等全局选项。

## 安装与连接

1. 安装前面下载的签名 APK。
2. 在首页点「前往配置」，新建连接或导入支持的 `.vpn` 格式配置。填写服务器地址和端口后，应用会尝试查询可用的虚拟 Hub。选择或手动填写 Hub，再填写登录凭据。新建配置默认使用端口 `443`，可从下拉列表选择 `8888`、`992`、`5555` 或自定义端口。
3. 在「设置 → 接入方式」中，未 Root 的设备请选择 TUN，并接受 Android 的 VPN 授权。需要二层接入时，在兼容设备上选择 TAP，并授予应用 Root 权限。
4. 回到首页点「连接」。出现 VPN 数据使用提示时请先阅读。若需要确认证书，请向服务器管理员核对。连接后可在「网络详情」查看地址、路由、接口名，以及当前会话的 TLS、数据加密和服务器证书信息。

| 接入方式 | 要求 | 转发能力 |
| --- | --- | --- |
| TAP（默认） | Root 和兼容的 Android 以太网集成 | 二层。转发以太网帧，包括 ARP、广播和组播。Android 配置地址与路由。 |
| TUN | Android `VpnService` 授权 | 三层。转发 IPv4 和可选的 IPv6，需要 VPN 侧的 IPv4 DHCP 租约。 |

两种模式使用 SoftEther v4.44-9807-rtm 原生核心。Rust TUN 引擎批量转发 IP 包和以太网帧，处理 IPv4 DHCP／ARP 及 IPv6 SLAAC／邻居发现。Kotlin 管理 Android VPN 接口、分流配置和应用界面。应用管理的连接默认使用 TCP/TLS 且关闭 UDP 加速。跨网段和公网访问取决于 VPN 侧的网关、路由及服务器配置。客户端不添加 NAT。

App 管理的 TAP 或 TUN 连接丢失当前 Wi-Fi 或移动网络时，会短暂等待可用网络并自动重连。切换期间，正在进行的传输可能会短暂中断。连接仍失败时，首页会显示原因及可用的 SoftEther 错误码。点「重新连接」可再试一次。

## 配置与证书

可在「配置」新建、改名、复制、编辑或删除连接。服务器、Hub、凭据、接入方式、IPv6 和分地址规则随配置保存。分应用名单、外观和通知选项全局共享。

证书信任按配置和服务器端点保存。应用在发送 VPN 登录凭据前检查服务器证书。需要手动确认时，通过可信渠道核对证书身份和指纹。证书更换后需重新验证。可在「配置 → 编辑 → 服务器证书」管理已保存的信任。

填好服务器地址和端口后，配置编辑页会自动查询服务器公开的虚拟 Hub。可点 Hub 输入框右侧的箭头选择，也可直接填写名称。查询时可核对并记住服务器证书。若地址或端口有改动，保存配置后，VPN 连接会复用这张证书。

TAP 和 TUN 支持匿名身份验证、标准密码验证、RADIUS 或 NT 域验证及客户端证书认证。使用客户端证书时需要导入 X.509 证书和配对的 RSA 私钥。应用通过 Android Keystore 加密保存私钥。Android 上的 SoftEther 核心暂无法使用智能卡登录。

`.vpn` 导入支持直连配置。导出文件包含连接设置，可用的用户凭据留在设备上。导入后按所选认证类型补齐所需凭据。分享文件前留意其中的服务器、Hub 和用户名。

## 分流与 IPv6

「分应用路由」默认为「所有应用」，「分地址路由」默认为「所有地址」。黑名单让所选应用或目的地址使用原网络，白名单只让所选项目通过 VPN。两项设置共同决定是否使用隧道。同一 UID 下的应用一起生效。

分地址规则支持 IP、CIDR 网段和精确域名。域名在连接时通过原网络解析为地址快照。修改规则或刷新域名结果需要重连。对于仅能在 VPN 内解析的域名，可填写对应 IP 或网段。

TAP 和 TUN 默认关闭 IPv6 转发，已有配置按各自保存的设置运行。开启后，TAP 由 Android 和 VPN 侧网络配置 IPv6，TUN 使用 SLAAC 和 IPv4 DNS。VPN 侧需要提供可用的路由器通告和路由。TAP 的 Root 分流受 Android 实现及固件影响，具体限制见 [Root 路由技术记录](docs/ROOT_ROUTING.md)。

## 外观、通知、日志与 TAP 管理

- 在主题设置中选择浅色、深色或跟随系统，并配置 Material 3 动态配色或强调色。
- 将 VPN 磁贴添加到系统快捷设置即可连接或断开。启用「通知栏显示流量」后，VPN 连通时会在通知中显示上传和下载速率。
- 在「设置 → 支持与信息 → 日志」开启「采集诊断日志」，可排查连接、TLS、地址分配和路由问题。关闭采集后，已有记录仍暂存在内存中，应用进程退出时清除。可点「导出」保存副本。
- TAP 模式下可通过「vpncmd 命令」管理独立的原生账号。电脑远程管理默认关闭，启用时需设置单独的管理密码。使用 `vpncmd PHONE_IP /CLIENT` 连接 TCP `9930`。管理协议本身未加密，请通过可信局域网或已有加密连接使用。

## 支持与隐私

提交问题时请附上应用版本、Android 版本、设备型号、接入方式，以及错误码或复现步骤。分享前请清除登录凭据、服务器地址等私有网络信息。[GitHub Issues](https://github.com/M0Sheng/Unofficial-SoftEther-VPN/issues)

VPN 流量发往你选择的服务器。服务器运营者负责转发和服务器端记录。诊断采集默认关闭，日志和配置导出文件可能包含服务器和网络信息。
